INTRODUCTION                                  *vim-lsp-settings-adapter*

This plugin allows using mattn/|vim-lsp-settings| with yegappan/|lsp| to easily
install and manage LSP servers for Vim 9.

CAVEATS

Some servers don't seem to work that well, depending on what configuration
needs to be transferred.  Currently initialization_options, workspace_config,
and root_uri are.

Multiple servers for a buffer are not supported.
